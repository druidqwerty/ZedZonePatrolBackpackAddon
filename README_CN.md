# ZED ZONE: 战术巡逻背包扩展与俄语汉化插件 (v1.0.0)

**特别应用户 `6VaN4!K96` 请求制作**

[![支持开发](docs/banner.png)](https://boosty.to/lrgpp)

本模组为 **[远征保鲜背包 (Workshop 3837676256)](https://steamcommunity.com/sharedfiles/filedetails/?id=3837676256)** 的扩展插件，将其完整的 `20×100` 独立分页、自动归类、零负重、食物保鲜与料理保温、跨页搜索和容器模式移植到原版 **战术巡逻背包 (`itemId = 513`)**，并补充完整俄语本地化与实用便捷功能。

## 主要功能

- **原版战术巡逻背包 (`ID 513`) 完整支持**：保留原版图标、角色外观和原版掉落池；旧存档中的巡逻背包自动安全扩容至 `20×100`，不丢失物品；原版远征背包仍可继续使用，默认关闭自动赠送 (`SuppressOriginalFreeGift = true`)。
- **完整俄语本地化 (`RU`)**：翻译所有分页标签、快捷预设、搜索框、右键菜单、规则计数、保护提示和内置操作指南。
- **新增便捷功能**：右键「原始」标签新增「+ 战术预设分页」一键创建常用分页（不重复创建，可在配置文件中自定义列表）；打开背包时支持 `PageUp` / `PageDown` 快速切换分页。
