# ZED ZONE: Аддон Тактического патрульного рюкзака + RU (v1.0.0)

**Специально по заказу для пользователя: `6VaN4!K96`**

[![Поддержать разработку](docs/banner.png)](https://boosty.to/lrgpp)

Аддон для оригинального мода **[Expedition Fresh Backpack (Workshop 3837676256)](https://steamcommunity.com/sharedfiles/filedetails/?id=3837676256)**, который переносит весь его функционал (независимые вкладки `20×100`, умную автосортировку, нулевой вес содержимого, сохранение свежести еды и тепла блюд, поиск по всем вкладкам и режим контейнера) на ванильный **Тактический патрульный рюкзак (`itemId = 513`)** и добавляет **полный 100% перевод на русский язык** без смешивания английского и русского.

## Возможности

- **Полная поддержка Тактического патрульного рюкзака (`ID 513`):**
  - Независимые вкладки `20×100` (2 000 ячеек на каждую вкладку), умная автосортировка по правилам, нулевой вес содержимого при ношении, сохранение свежести еды и тепла горячих блюд, поиск по всем вкладкам, режим контейнера (на земле и в сундуках).
  - Сохраняет родную иконку, модель на персонаже и наличие `513` в ванильном луте.
  - **Безопасный апгрейд старых сохранений:** уже имеющиеся у вас патрульные рюкзаки (надетые или в контейнерах) автоматически расширяются с ванильного размера до `20×100` без потери и сдвига вещей.
  - Оригинальный рюкзак `925722`/`925721` продолжает работать; автовыдача бесплатного `925722` при первом запуске отключена по умолчанию (`SuppressOriginalFreeGift = true`).
- **Полный русский перевод (`RU`):**
  - Переведены 100% элементов `ZedBackpack`: вкладки («Основной», «+ Новая», «Вкладка»), все 8 коротких и полных пресетов (`Ор/Оружие`, `Пт/Патроны`, `Ме/Медицина`, `Ед/Еда`, `Пр/Припасы`, `Мт/Материалы`, `Ин/Инструменты`, `Об/Обвесы`), поиск («Поиск предметов»), меню ПКМ, счётчики правил, уведомления защиты, справка «? Справка» и описания предметов.
  - Предзагрузка кириллических глифов и мгновенное переключение языка `RU / EN / ZH` на лету.
- **Дополнительные удобства:**
  - **Кнопка «+ Набор вкладок»** в ПКМ-меню вкладки «Основной» — создаёт стартовый набор (`Оружие`, `Патроны`, `Медицина`, `Еда`, `Материалы`, `Инструменты`) в один клик без дублирования уже существующих вкладок. Список можно задать свой в конфиге (`CustomPresetPack`).
  - **Быстрое переключение вкладок `PageUp` / `PageDown`** при открытом инвентаре рюкзака (не мешает чату, поиску, переименованию и перетаскиванию).
  - **Конфиг (`BepInEx/config/com.druid.zedzone.patrolbackpackaddon.cfg`):** настройка всех опций, включая опциональный крафт патрульного рюкзака (`CraftablePatrolBackpack`, по умолчанию выключен).

## Требования и установка

1. Установите сторонний **[ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258)** (один раз запустите `install.cmd`).
2. Подпишитесь на оригинал **[Expedition Fresh Backpack (3837676256)](https://steamcommunity.com/sharedfiles/filedetails/?id=3837676256)**.
3. Подпишитесь на этот аддон в Steam Workshop (или распакуйте папку `PatrolBackpackAddon/` из релиза GitHub в `ZED ZONE/Mods/`).
